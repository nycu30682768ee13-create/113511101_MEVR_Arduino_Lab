1. 實驗目標

學習超音波感測器模組（HC-SR04）的操作原理與使用方法，以進行距離量測。

學習伺服馬達（SG90）的腳位定義與控制方式。

掌握將感測器輸入轉換為動作輸出的邏輯，實現根據量測到的距離來控制伺服馬達角度的功能。


2. 設備與元件

Arduino Uno 開發板 x 1

USB Type-B 傳輸線 x 1

個人電腦（已安裝 Arduino IDE）x 1

麵包版 x 1

超音波感測器 (HC-SR04) x 1

伺服馬達 (SG90) x 1

杜邦線 x 若干

障礙物（如水瓶或紙盒等） x 1


3. 操作說明與成果

硬體接線與燒錄：自行查閱並了解 HC-SR04 與 SG90 的腳位配置。將 HC-SR04 的 VCC 與 GND 接至電源，Trig 與 Echo 腳位連接至 Arduino 的數位腳位；將 SG90 的電源與接地線接好，並將訊號線連接至 Arduino 具備 PWM 功能的腳位。使用 USB 線連接 Arduino Uno 至電腦並上傳程式碼。

實驗成果：

在超音波感測器（HC-SR04）前方放置障礙物（如水瓶），並前後移動改變其與感測器之間的距離。

伺服馬達（SG90）的轉動角度會隨著障礙物距離的遠近產生對應的變化。

成功完成利用超音波感測器測距來連動驅動伺服馬達角度之目標。
