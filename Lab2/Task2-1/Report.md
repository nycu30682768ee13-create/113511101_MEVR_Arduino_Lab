1. 實驗目標

學習將可變電阻整合至馬達控制電路中。

掌握利用類比輸入訊號（可變電阻角度）轉換為邏輯與 PWM 訊號，以同時控制 DC 馬達的轉向與轉速。

熟練設定數值區間映射（Mapping），實現旋鈕置中停止、向兩側旋轉即反向且加速的控制邏輯。


2. 設備與元件

Arduino Uno 開發板 x 1

USB Type-B 傳輸線 x 1

個人電腦（已安裝 Arduino IDE）x 1

麵包版 x 1

可變電阻 x 1

杜邦線 x 若干

DC馬達 x 1

L293D x 1


3. 操作說明與成果

硬體接線與燒錄：將可變電阻的左右兩腳位分別接至 5V 與 GND，中間訊號腳位連接至 Arduino 的類比輸入腳位（如 A0）。將 L293D 馬達驅動晶片與 DC 馬達依電路圖連接，並將控制腳位接至 Arduino 具備 PWM 功能的數位腳位。使用 USB 線連接 Arduino Uno 至電腦並上傳程式碼。

實驗成果：

將可變電阻旋鈕轉至「正中間」位置時，馬達保持靜止不動。

將旋鈕向右（順時針）旋轉時，馬達開始順時針轉動，且旋轉角度越大，順時針轉速越快。

將旋鈕向左（逆時針）旋轉時，馬達開始逆時針轉動，且旋轉角度越大，逆時針轉速越快。
